# DraveWriter

Maak je eigen receptenboek of een gewoon boek. Recepten met foto, ingrediënten en stappen; de voedingswaarden per portie rekent DraveWriter zelf uit met de NEVO-tabel van het RIVM (offline, onveranderd; eigen waarden krijgen een *). Meer of minder personen rekent netjes afgerond mee. Een gewoon boek schrijf je in hoofdstukken met plaatjes. Kaft, inhoudsopgave en bladzijdenummers komen vanzelf; bewaar als PDF of maak hem klaar voor de drukker (binnenwerk + kaft met rug). Voedingswaarden: gebaseerd op gegevens van NEVO-online versie 2025/9.0, RIVM, Bilthoven.

## Voedingswaarden / Nutrition data

De voedingswaarden zijn gebaseerd op gegevens van **NEVO-online versie 2025/9.0, RIVM, Bilthoven**.
Het originele NEVO-bestand (`NEVO/NEVO2025_v9.0.zip`) wordt onveranderd meegeleverd en gebruikt; eigen waarden van de
gebruiker staan er apart bovenop en worden in het boek gemarkeerd met een sterretje (*).
Voorwaarden van het RIVM: zie `Voorwaarden voor gebruik NEVO-online 2025 databestand.pdf` in de zip,
en de nieuwste versie op <https://www.rivm.nl/nevo-online>. De waarden zijn schattingen; het RIVM aanvaardt geen
aansprakelijkheid voor fouten of verkeerd gebruik.

Nutrition values are based on data from **NEVO-online version 2025/9.0, RIVM, Bilthoven** (the Dutch food composition
database). The original NEVO file is included unchanged; your own values are kept separately and marked with *.

## ⬇️ Downloaden (Windows, geen Python nodig)

### [👉 Download DraveWriter 0.2.1](https://github.com/mbrv4ever/DraveWriter/releases/latest)

1. Klik op de link en download het **.zip**-bestand.
2. Pak het uit: rechtsklik → **Alles uitpakken...**
3. Dubbelklik op **DraveWriter.exe**.

> Zie je een blauw scherm "Windows heeft uw pc beschermd"? Klik op **Meer informatie** → **Toch uitvoeren**.

## Vanaf de broncode

Installeer Python 3.10 – 3.13 en de benodigde pakketten (zie `requirements.txt` als die er is), en start het hoofdbestand (`.py`). Eventuele `.bat`-bestanden doen dit voor je.
